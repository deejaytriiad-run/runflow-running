# RunFlow

Application personnelle et gratuite de suivi running.

## Fonctionnalités

- tableau de bord et statistiques
- ajout manuel, historique et suppression des sorties
- objectifs et planification hebdomadaire
- sauvegarde locale dans le navigateur
- import de l'historique Strava depuis l'archive officielle `activities.csv`
- interface responsive, sans Apple Santé ni abonnement

## Données

Les données restent dans le `localStorage` du navigateur. L'import Strava est traité localement : le fichier n'est envoyé à aucun serveur.

## Publication

Le site est déployé automatiquement avec GitHub Pages à chaque mise à jour de la branche `main`.
